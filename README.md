# AVÉRO — Objects Made Personal

Mobile-first premium storefront for personalised 3D-printed gifts, keepsakes, home objects and bespoke creations.

## Preview
Open `index.html` in a browser or deploy this repository as a static site on Vercel. No build step required.

## Included
Responsive premium homepage, mobile menu, collections, product concepts, bespoke enquiries and basic SEO.

## Before launch
1. Replace concept imagery with real product photography and add accurate prices.
2. Replace placeholder `hello@example.com` with a working business email.
3. Connect Square Payment Links for fixed-price products or Square Checkout API through a secure backend for customised orders. Never expose API tokens in frontend code.
4. Add order confirmation, delivery, returns, privacy and contact information.
5. Test on mobile, connect domain and deploy.

**This is a preview only:** checkout is not enabled, and product images are illustrative placeholders.
